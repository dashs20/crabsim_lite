# CrabSim Lite

![CrabSim Lite Logo](crablite.png)

CrabSim Lite is a lightweight, Python-based dynamics simulation environment designed for modeling rigid bodies equipped with rotors. It provides a modular approach to simulating complex interactions between body motion, rotor reaction torques, and thrust-generated moments.

## Features

- **Rigid Body Dynamics:** Simulate 3-DOF angular dynamics of a rigid body.
- **Advanced Rotor Modeling:** Supports modeling rotors as both reaction wheels (for torque) and thrusters (for force).
- **Numerical Integration:** Uses a robust Runge-Kutta 4th order (RK4) integrator for accurate state updates.
- **Modular Design:** Easily swap out plant models, actuators, and integration methods.
- **Data Logging & Visualization:** Built-in support for logging simulation data to CSV and generating PDF reports.

## Installation

Ensure you have Python 3.x installed. You can install the required dependencies using pip:

```bash
pip install -r requirements.txt
```

The core dependencies are:
- `numpy`: For numerical computations and matrix operations.
- `matplotlib`: For generating plots and visualizations.

## Project Structure

- `plants.py`: Contains physical models for rigid bodies and rotors.
- `integrator.py`: Implements the RK4 integration algorithm.
- `util.py`: Utility functions for inertia calculations, unit conversions, and lookup tables.
- `test_sim.py`: An example simulation script demonstrating how to set up and run a model.
- `csv_to_pdf.py`: A post-processing script to convert simulation logs into PDF plots.

## Quick Start

1. **Run a Simulation:**
   Execute the `test_sim.py` script to run a pre-configured simulation. This will generate a `log.csv` file.
   ```bash
   python test_sim.py
   ```

2. **Visualize Results:**
   Use the `csv_to_pdf.py` script to process the log and generate a visual report.
   ```bash
   python csv_to_pdf.py
   ```
   The output will be saved as `log.pdf`.

## Core Components

### `simple_rigid_body`
A class representing a 3D rigid body defined by its inertia tensor. It handles state updates using the provided integrator.

### `rotor_as_wheel`
Models the reaction torque generated by a rotor's angular acceleration and gyroscopic effects.

### `rotor_as_thruster`
Models the force and resulting moment generated by rotor thrust, based on lookup tables for motor performance.
